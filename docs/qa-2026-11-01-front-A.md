## 1. 정한 이름 (12번)

규칙: **드로어 소메뉴 = 페이지 제목(h1) = 경로 표시 마지막 칸 = 탭 제목**. 그 화면으로 가는 버튼도 같은 이름을 쓴다.

| 화면 | 대메뉴(헤더 · 하단 탭 · 드로어) | 소메뉴 · 페이지 제목 · 탭 제목 | 버튼 | 바꾸기 전 |
|---|---|---|---|---|
| `/notices` | 공지 | 공지 목록 | 전체보기(홈) · 공지 목록으로(상세) | 대메뉴 "공지사항"(드로어) / "공지"(헤더), 제목 "공지사항" |
| `/notices/:id` | 공지 | (공지 제목) | — | 경로 마지막 칸 "공지 목록" |
| `/weekly` | 내 활동 | 주간 활동 | — | 제목 "내 주간 활동" |
| `/teams` | 팀 | 내 팀 | — | 소메뉴 "내 팀 목록" |
| `/teams/join` | 팀 | 팀 참가 | 팀 참가(홈 · 내 팀) · 제출 버튼 팀 참가 | 버튼 "초대코드 입력", 제출 "참가하기" |

## 4. 다른 세션과 겹침

### 같은 파일을 두 세션이 고침

- `src/features/home/home.module.css`: A는 `.moreLink`(전체보기 누름 영역) 추가, B는 토큰 치환. 지금 파일에 둘 다 들어 있다. 먼저 커밋하는 쪽이 두 변경이 함께 든 지금 파일을 올리면 된다.
- `src/shared/ui/WeekStrip/WeekStrip.test.tsx`: A는 문구("잔디 없음" → "기여 없음", `strip.ts`와 짝), B는 범례 테스트(`WeekStrip.tsx`와 짝). 이 테스트 파일은 `strip.ts`와 `WeekStrip.tsx`가 둘 다 있어야 통과한다. **두 세션 변경을 한 커밋에 넣거나, 나중에 커밋하는 쪽이 이 파일을 올린다.**

### A 커밋에 실제로 넣은 것 (B가 아직 올리기 전)

- A가 먼저 커밋했다. 겹치는 두 파일은 develop 원본에 **A 변경만** 얹어 올렸다: `home.module.css`는 `.moreLink`만 추가(B의 토큰 치환은 B 커밋 몫), `WeekStrip.test.tsx`는 "잔디 없음" → "기여 없음"만(B의 범례 테스트는 B 커밋 몫). B는 커밋 전 `git pull --rebase` 뒤 지금 작업 폴더의 두 파일을 그대로 올리면 된다.
- 모바일 글쓰기 버튼은 B의 `--tap` 토큰을 쓰므로 B 커밋 전에도 깨지지 않게 `var(--tap, 44px)`로 적었다.
- clone에서 `npm ci && npm run check` 통과(테스트 699 — B의 범례 테스트 1건이 빠진 수).

### 다른 세션 범위라 손대지 않은 것

- **잔디 히트맵 읽기 문구**: `GrassHeatmap.tsx`도 기여가 없는 날을 "잔디 없음"으로 읽는다(15번과 같은 문제). B 담당 파일이라 고치지 않았다. 109번째 줄의 `'잔디 없음'`을 `'기여 없음'`으로 바꾸면 맞춰진다.
- **px 글자 크기 · 모서리**: B 문서 4절대로 A 파일(`activity.module.css`, `HeaderSearch.module.css`, `HeaderNav.module.css`, `PostListPage.module.css` 등)에 px 값이 남아 있다. 이번에 A가 새로 넣은 CSS는 토큰(`--tap`, `--radius`)이나 기존 값만 썼다.
- **게시판 빈 상태와 검색칸 사이 간격**: 빈 상태가 흰 상자로 바뀐 뒤(B 6번) 검색칸 바로 아래에 붙어 보인다(태그가 없을 때). 간격은 B의 빈 화면 모양 통일과 함께 정하는 게 맞아서 두었다.
