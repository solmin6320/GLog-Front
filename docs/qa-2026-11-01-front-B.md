## 5. 다크 모드 계획 (이번엔 안 함)

1. `tokens.css`에 `@media (prefers-color-scheme: dark) { :root { ... } }`로 색 토큰만 다시 정의한다. 화면 CSS는 이미 토큰만 쓰므로 고칠 곳이 적다. 먼저 하드코딩 색(`#fff`, `rgba(...)`)을 찾아 토큰으로 바꾼다(`GrassHeatmap` 툴팁 `#fff` 등).
2. 잔디 단계(`--h0`~`--h4`)는 어두운 배경용으로 따로 정한다(GitHub 다크 잔디처럼 낮은 단계가 어둡게).
3. `:root { color-scheme: light dark; }`와 `index.html`의 `theme-color`를 두 개(`media` 속성)로 나눈다.
4. 아바타 · 링크 · 상태 색은 어두운 배경 위 대비 4.5:1을 다시 잰다.
5. 수동 전환(설정 화면)은 그다음 단계. 처음엔 OS 설정만 따른다.
